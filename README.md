Это пример WebSocket сервера для SC Web.

В [assets/extension.js] находится расширение для Dash которое нужно для взаимодействия.

Смотрите ветки для списка версий

# Установка

1. Установите npm, node и git
2. Промежуточный шаг: если хотите вносить изменения, создайте форк, а в следущем пункте укажите репозиторий вашего сервера
3. Выполните git clone https://github.com/DiamondCatGroup/sc-web-servers.git
4. Выполните npm i для установки зависимостей

# Запуск

1. [https://github.com/DiamondCatGroup/sc-web-servers#Установка|Установите] если ещё не установили
2. Создайте config.json, в качестве основы используйте [example.config.json]
3. Выполните npm start
4. Сервер доступен на localhost:3000, 127.0.0.1:3000, [локальный ip вашего устройства в сети]:3000 и если у вас не CGNAT то [ваш ip]:3000. WebSocket находится по пути /ws
5. localhost, 127.0.0.1 доступны только с вашего компьютера, а локальный ip вашего устройства только в вашей сети.
6. Если у вас CGNAT для того чтоб сервер был доступен всем в другой сессии терминала выполните npm run start-lt. URL сервера lt скажет вам сам.
