Это пример WebSocket сервера для SC Web.
В [assets/extension.js] находится расширение для Dash которое нужно для взаимодействия.
Для запуска: установите Node.js и npm, выполните npm i, выполните npm start - готово. сервер будет на ws://localhost:3000/ws / ws://127.0.0.1:3000/ws / если  не CGNAT ws://[ваш ip]:3000/ws
Если у вас CGNAT то сервер будет доступен только тем кто в той же сети что и вы.
npm run start-lt для запуска localtunnel. URL будет: scwebserver.loca.lt если сейчас не занят, иначе что-то рандомное
Смотрите ветки для списка версий
